# Course project brief (DALAS, as posted by the teacher)

Copied verbatim from the course page on 2026-10-12 so both of us work from the same text.
Deadlines: midnight on the day of the TME.

## Deliverable 1, TME 4 (10%)
Two-page report containing:
- the research question(s),
- a quantitative description of the collected dataset, together with a description of the data collection process.

It should include information such as the number of observations, the variables collected, their meaning,
and any relevant preprocessing already performed. Choices made must be explained.

## Deliverable 2, TME 6 (25%)
Dashboard for exploring the dataset. May focus on a subset or a transformed summary. The teacher must be able
to run it easily. Not default visualisations (distributions of every variable, default clustering); tailored
to the data (maps for geography, time series for temporal data, readable heatmaps with selected variables,
log transforms where needed). Does not yet need to answer the research question.

## Deliverable 3, TME 9 (65%)
Visual report: at most 2,500 words and 12 pages including figures, PDF (preferably LaTeX) or interactive HTML
that prints in about 12 pages. A clear, professional, data-driven investigation. Examples given: peak population,
climate change and agriculture, student population in the UK.
Plus: all code used for the report, and a technical report on data preparation, implementation, parameter
choices and other technical decisions.
Grade = average of (a) report quality (report, figures, question, methods, interpretation, data quality) and
(b) overall work during the semester (weekly discussions, code quality, involvement, final oral).

## Dataset rules
- Build your own dataset via APIs and/or scraping from one or several sources; more than a single Wikipedia table,
  multiple items combined into one dataset. Enriching with other sources is encouraged.
- An existing dataset only if real-world and complex enough to need meaningful preprocessing.

## Question rules
- Questions about the real world, not about the dataset ("where is climate change strongest", not
  "what clusters are in this dataset" or "which method predicts best").
- Not graded on answering the question, but on applying the process: understanding data and limitations,
  preparing it correctly, appropriate methods, interpretation. Partial answers are fine if reached correctly.
- The question may be refined during the semester while keeping the overall objective.
